# One-O Product Decisions (defaults)

User instruction: "use defaults". Every answer below is `ASSUMPTION (confirm with customer)`. Owner: product-manager (D-01..D-04, D-13), system-requirements-engineer topics answered here as defaults pending their refinement.

| ID | Open question | Default answer | Rationale |
|---|---|---|---|
| D-01 | Boot targets and market/OEM | Cold boot to interactive HMI <= 10 s (splash <= 3 s), warm/resume <= 3 s. Market: generic passenger-car OEM, EU + North America. ASSUMPTION (confirm with customer) | Typical IVI expectation; keeps vision.md metrics; generic OEM avoids brand lock-in. |
| D-02 | Radio in MVP? Tuner hardware? | AM/FM radio NOT in MVP (US-016 to R2). Reference hardware has no tuner fitted. ASSUMPTION (confirm with customer) | Tuner is hardware-dependent and adds RF/regulatory work; media is covered by USB + BT. |
| D-03 | Rear camera in MVP? Camera hardware? | Rear camera NOT in MVP (US-012 to R2). Reference hardware exposes one analog/MIPI camera input for later use. ASSUMPTION (confirm with customer) | Reverse-camera has latency/safety implications; defer until display pipeline and gear signal are proven. |
| D-04 | Languages and regions at launch | English (en-US) and German (de-DE); metric and imperial units; EU + US regions. Runtime switch, no reboot. ASSUMPTION (confirm with customer) | Satisfies US-008 (>= 2 languages); string externalisation lets more be added later. |
| D-05 | OTA update in MVP? | MVP supports image/partition design that allows OTA (A/B rootfs, version metadata) but no OTA backend or client UI. Full OTA in R3. ASSUMPTION (confirm with customer) | Matches vision goal 4 ("path to OTA") and out-of-scope OTA backend; avoids costly rework later. |
| D-06 | CAN signals / D-Bus services for vehicle settings subset | Read: vehicle speed, gear, door-open, lamp warnings, ignition state, ambient/headlight status. Set: exterior/interior lighting mode, units (metric/imperial), climate display unit/mode. CAN 500 kbit/s, vendor DBC supplied by OEM, mock DBC for dev. D-Bus: `org.oneo.VehicleSignals` on system bus fronting the CAN gateway. ASSUMPTION (confirm with customer) | Smallest set that satisfies US-010/011/007/022; D-Bus facade keeps UI off the bus (US-009). |
| D-07 | Target SoC, RAM, display | ARM Cortex-A, quad-core i.MX8M-class SoC with GPU (OpenGL ES); 2 GB LPDDR4; 8 GB+ eMMC; 10.25 in 1280x720 capacitive touchscreen, 60 Hz. ASSUMPTION (confirm with customer) | Common IVI-class platform with good Yocto/Qt support; 2 GB gives headroom over the 512 MB idle target. |
| D-08 | Driver-distraction standard and speed threshold | Follow NHTSA Visual-Manual Driver Distraction Guidelines (US) and use ISO 15005 / ISO 15007 principles for EU. Lockout above 8 km/h (5 mph), configurable. Locked while driving: text entry, long list browsing, pairing, settings editing. ASSUMPTION (confirm with customer) | NHTSA guidelines are the common public reference; low default threshold is conservative; configurability per US-022. |
| D-09 | Audio routing / ducking priorities | Priority high to low: (1) safety/chime alerts, (2) phone call (HFP) and ringtone, (3) navigation/system prompts (future), (4) media. Alerts duck media -20 dB; calls pause media and resume after call ends. Single audio sink with per-stream volume; volume persists across reboot. ASSUMPTION (confirm with customer) | Standard IVI arbitration; satisfies US-019 and US-015. |
| D-10 | Bluetooth profiles | MVP: A2DP sink, AVRCP 1.5 (controller + metadata), HFP 1.7 (hands-free unit), PBAP client. R2: MAP client (US-021). BT 5.0 classic + LE, pairing via Secure Simple Pairing with numeric comparison, 5 paired devices. ASSUMPTION (confirm with customer) | Covers US-014, 018, 019, 020; MAP deferred as Could. |
| D-11 | Secure boot and signing | SoC assumed to support HAB-style secure boot (signed bootloader/kernel); rootfs integrity via dm-verity; image signing keys held by OEM release process. If hardware lacks support, MVP ships signed images verified at update time and the gap is a documented risk. ASSUMPTION (confirm with customer) | Meets US-023 "where SoC supports it"; i.MX8-class SoCs support secure boot. |
| D-12 | Idle memory budget | Idle footprint <= 512 MB of 2 GB, retained from vision.md. ASSUMPTION (confirm with customer) | Consistent with D-07. |
| D-13 | MVP media sources | USB audio (MP3, FLAC, AAC) and Bluetooth audio only. ASSUMPTION (confirm with customer) | Follows from D-02; both hardware-independent of tuner. |
